Tips

🎮 Best Performance

Use the ANGLE renderer for Minecraft 1.17+. For older versions (1.16 and below), use Holy GL4ES 1.1.5.

☕ No JIT? Use Half-JIT

If you can't enable JIT, go to Settings → Java Runtime and switch to java-8-openjdk-halfjit. It's slower but works without any external tools.

🧩 Mod Compatibility

Avoid Sodium and ImmediatelyFast — they are not compatible with iOS rendering. Use OptiFine instead for performance and shaders.

Known Issues

⚠️ Performance mods

Mods that replace the rendering pipeline (Sodium, ImmediatelyFast) crash on iOS. Use OptiFine instead.

⚠️ Non-jailbroken limitations

Without JIT, performance is reduced. Half-JIT runtime is available as a workaround but expect slower gameplay on modern Minecraft versions.
